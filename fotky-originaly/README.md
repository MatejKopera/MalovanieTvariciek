# Originálne fotografie

Aktívne podklady pochádzajú priamo z Figmy. Tento priečinok sa neposiela do Gitu ani na verejný web.

- `figma-fotografie/`: spoločné zdroje pre náhľady aj zväčšenie 33 fotografií galérie a piatej fotografie hlavnej stránky. Rovnaký podklad a otočenie sa používajú pre obe verzie.
- `figma-uvod/`: priehľadné fotografie detí a ozdobné tvary úvodu.

Web používa výlučne optimalizované verzie vo `fotky-web/`. Obnova: `python scripts/prepare_assets.py`. Pôvod a rozmery zdrojov sú v `scripts/figma-photo-sources.json`.

Staré ručné exporty, duplicitné stiahnutia a nepoužívané webové obrázky sú zálohované mimo tohto priečinka: `.qa/archiv-povodne-podklady-20261029.zip`. Pre aktuálny web ich netreba.

Staršie samostatné podklady náhľadov a nahradené webové varianty sú v `.qa/archiv-pred-opravou-obrazkov-20261029.zip`. Aktívny priečinok obsahuje iba podklady používané spoločným postupom spracovania fotografií a úvodu.
